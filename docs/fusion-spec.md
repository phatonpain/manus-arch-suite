# Design & Architecture Fusion Specification

This document details how to harmonize multiple disparate design tools and templates into a single high-performance frontend.

## 1. Visual Hierarchy & Tokens (Figma / Canva)
- **Base Background**: `#09090b` (Deep Zinc / Obsidian)
- **Surface Elevation**: `#141417` with `border border-white/10` and `backdrop-blur-md`
- **Accent**: `#c69b6d` (Architectural brushed bronze/gold)
- **Typography**: 
  - Headlines: Modern geometric grotesque (`Space Grotesk`, `Inter`)
  - Subheadings / Badges: High-contrast uppercase tracking (`tracking-wider`, `text-xs`)

## 2. Bento Grid & Micro-interactions (Framer S26)
- Grids are 12 columns with responsive breakpoints:
  - Mobile: 1 column (`grid-cols-1`)
  - Tablet: 6 columns (`md:grid-cols-6`)
  - Desktop: 12 columns (`lg:grid-cols-12`)
- Bento cards feature subtle inner glow on hover: `hover:border-brand-accent/40 transition-colors duration-300`.

## 3. 3D Spline Experience
- The 3D view is positioned in the Hero or Interactive Preview section.
- Spline scenes must never block the main thread during initial page load. Always render a lightweight skeleton fallback.
- Set `pointer-events-none` on overlay elements so users can interact with the 3D model effortlessly.

## 4. Redraw Architecture Comparison
- The Before/After component compares:
  - Side A: Architectural floor plan / wireframe / raw construction.
  - Side B: AI photorealistic rendering generated by Redraw architecture models.
- Controls include a responsive divider slider responding to mouse and touch dragging.
